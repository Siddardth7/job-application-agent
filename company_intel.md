## How to use
- Before shortlisting, match each candidate's company against this table.
- SKIP -> remove from the shortlist entirely, with a one-line note ("skipped per intel: not hiring OPT").
- CAUTION -> keep on the shortlist but add the caveat to the Why/Visa column so Sid decides with eyes open.
- POSITIVE intel (e.g. "this manager said they actively sponsor") -> note it and rank the company up.
- Keep entries dated; if intel changes (a company reverses a policy), update the row rather than deleting history - add a new dated line.
